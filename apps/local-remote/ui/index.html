Listening Room DJ Mac

Single control plane for this Mac: Redis / OSC / Farrago soundboard, plus Media Bridge (supervised Node child). Bookmark http://127.0.0.1:9876/ only. Open the Farrago soundboard on the same origin.

Connection

rediss:// for TLS. If logs show UnknownIssuer (local-remote) or SELF_SIGNED_CERT_IN_CHAIN (Media Bridge), append /#insecure (e.g. rediss://:pass@host:port/#insecure). Skips cert verification—only on trusted networks. This URL is injected into the bridge child.

Used for Fetch ready shows / segment list. The platform exposes read-only /api/public/scheduling/* endpoints (no login). Production API must allow this origin in CORS (see LOCAL_REMOTE_URL if you change HTTP listen).

Pick segments (ready shows)

Fetches ready shows via the platform’s public scheduling API (no login), then loads segment names. Click a segment to add an OSC mapping row (segment id matches SEGMENT_ACTIVATED in Redis). Requests use whatever is currently in Platform API URL above.

    OSC (SEGMENT_ACTIVATED)

    Use 127.0.0.1 when Farrago runs on this Mac.

    Must match OSC Input port in Farrago Settings → Controllers.

    Sends /ping to the host and port above (see Farrago OSC). Success = UDP send OK (see bytesSent). Farrago often does not reply back to this app—it sends responses to OSC Output, so replyReceived: false is common and not proof of failure. Same Mac as Farrago: try 127.0.0.1. For tiles, use default args (e.g. 1) with /set/…/play or /select. No save required for this button.

    Sent as float32 after the address on every trigger (many Farrago endpoints expect a value).

    Select a Farrago tile from the dropdown, or choose Custom path… for manual OSC entry. Use Test on a row to send that path with the default args (same as a live trigger; no save required). Refresh tiles fetches the latest tile list from Farrago.

    Farrago soundboard (optional)

    Listens for Farrago OSC Output on the UDP port below and serves /soundboard. Requires OSC enabled above (same host/port are used to send /ping and tile /play).

    In Farrago → Settings → Controllers, set OSC Output to 127.0.0.1 and this port (must differ from Farrago OSC Input port).

    Now Playing (macOS watcher)

    Watches the macOS Now Playing center. When Media Bridge is enabled below, this watcher is forced off so the bridge owns Now Playing.txt (no double publish).

    Media Bridge is enabled — use the bridge Now Playing path below for Audio Hijack.

    Media Bridge

    Supervised child process (bundled Node + bridge-daemon). Redis URL for the child is injected from Connection above. Bridge-specific settings save to ~/.config/listening-room-bridge/config.json.
